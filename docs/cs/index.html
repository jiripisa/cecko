Cecko

Jednoduchý a hezký editor C++ pro studenty: napiš kód, zmáčkni Run a hotovo.

Stáhnout pro macOS Verze 0.1.0 pro macOS 27 a novější. Přečtěte si manuál.

Co umí

Napiš, zmáčkni Run, hotovo

Žádné projekty, žádné nastavování, žádné přepínače kompilátoru. Otevři soubor .cpp, zmáčkni Run a program se přeloží a spustí. Pro studenty, kteří s C++ teprve začínají.

Opravdová konzole

Programy běží v konzoli přímo v okně a chovají se stejně jako v Terminálu: výzva se ukáže dřív, než program čeká na vstup, a vstup píšeš rovnou tam. Tlačítko Stop ukončí program, který se zacyklil.

Chyby na správném řádku

Když se kód nepřeloží, řádek s chybou se zvýrazní a hláška kompilátoru je hned vedle něj. Kliknutím na hlášku v konzoli skočíš na její řádek.

Čtyři vzhledy

Čistý Glass s Liquid Glass, zelený Hacker, neonový Synthwave a ostrý Cyberpunk. Otevře i kód z Code::Blocks na Windows, včetně české diakritiky a bits/stdc++.h.

Stáhnout

Obraz disku je podepsaný a notarizovaný Applem, takže se otevře bez bezpečnostních varování. Přetáhni Cecko do složky Aplikace.
