Cecko

A simple C++ editor for students: write code, press Run, done.

Download for macOS Version 0.1.0 for macOS 27 or later. Read the manual.

What it does

Write, press Run, done

No projects, no settings, no compiler flags. Open a .cpp file, press Run and your program compiles and starts. Made for students who are just starting with C++.

A real console

Programs run in a console inside the window and behave just like in Terminal: prompts show up before the program waits, and you type the input right there. Stop ends a program stuck in a loop.

Errors on the right line

When the code doesn't compile, the line with the mistake lights up and the compiler's message sits right next to it. Click a message in the console to jump to its line.

Four looks

Clean Glass with Liquid Glass, green-on-black Hacker, neon Synthwave and sharp Cyberpunk. Code from Code::Blocks on Windows opens too, Czech characters and bits/stdc++.h included.

Download

The disk image is signed and notarized by Apple, so it opens without security warnings. Drag Cecko to Applications.
